# 开发期审计签名边界

- 签名身份：运行 OpenCode 与质量门禁的当前 Windows 开发用户。
- 私钥位置：`CurrentUser/My` Windows 证书存储区；私钥不可导出，不进入仓库、日志或模型上下文。
- 仓库内容：固定公钥证书、证书 SHA-256、指纹、规范化链头和 detached CMS 签名。
- 门禁要求：签名前检查唯一证书、私钥可用且 PFX 导出失败；质量门禁最终状态必须为 `fully-sealed`。
- 沙箱边界：只读验签不需要私钥；重新签封必须获准访问当前用户证书存储区。
- 算法边界：RSA-3072/SHA-256 仅用于本地开发原型，不构成正式密码合规结论。正式环境必须替换为批准的 SM2 密码产品、受控证书签发和独立审计节点。
