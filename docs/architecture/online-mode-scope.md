# 在线协同实现范围声明（Online-Mode Scope）

> 状态：生效（2026-08-10，ARCH-REVIEW-13；落实架构审查 P1-2 收口）
> 适用范围：对外汇报、能力矩阵、后续版本规划

## 1. 双模式要求与 MVP 实际范围

- 约束文档 §2 要求系统"同时支持"受控网络协同模式与物理隔离离线模式；
- **MVP 实际实现并验证的是离线闭环**：`.agent` 加密包流转、本地工作区、
  两条固定编排链、本地驾驶舱，全部断网可复现（E2E 断网黑盒
  external_requests=0）；
- **受控网络协同模式（§2.1）当前为设计态**：节点注册/状态上报、实时或准实时
  事件同步、跨节点消息通道、运行中枢对在线节点的动态编排均**未实现**；
  capability-status 中"中心端持久化/跨节点同步"保持 `DESIGNED` / `MODELED`。

## 2. 声明纪律

1. 对外汇报不得声称"分布式在线协同已建成"或"系统为实时分布式系统"；
   正确表述为"离线闭环已验证，在线协同为后续版本范围"；
2. 任何"在线协同模式已实现"的声明必须先关闭 `external-gates.md` 对应门禁并
   通过独立安全审查；
3. 新增在线协同实现必须遵循 `orchestrator-seam.md` 无旁路规则与
   `ports-adapters.md` 分层契约，并同步更新本契约。
