# Windows 7 兼容分支专项（Win7 64-bit 任务运行环境）

> 状态：approved scope（2026-08-02）。对应强制约束 §4.2 与
> MVP 参考架构 §5.2。Win7 仅为存量环境兼容分支，不是系统长期安全基线。

## 1. 独立分支

Win7 兼容工作全部在独立分支 `win7-compat` 上进行，与主分支（正式安全
基线）分开构建、发布与测试。主分支不得为兼容 Win7 而降级密码算法、
依赖或安全约束。

## 2. 冻结依赖与构建

- 仅使用 Python 标准库 + 仓库锁定工具链（`.tools/` 哈希锁定）与锁定
  GmSSL 3.2.0 原型（`mvp-prototype`）；不引入任何需要 Win7 不支持
  API 的第三方包。
- 依赖冻结：`docs/dependencies/toolchain-lock.json` 为唯一来源，禁止
  运行时下载；Win7 分支使用与主分支相同的锁文件（如 Win7 下发现不兼容
  组件，先离线审批并单独记录版本差异）。
- 目标运行时：Windows 7 SP1 x64（含 PowerShell 5.1；不要求 Win7 运行
  OpenCode/Codex 自身）。

## 3. 功能范围

| 级别 | 功能 |
|---|---|
| 支持 | `.agent` 任务包导入/导出、安全校验与原子导入；本地工作区初始化；本地驾驶舱（系统浏览器访问环回服务）；WPS 文档打开；进展手工确认；基础成果包生成；本地审计与异常拦截 |
| 降级 | 驾驶舱渲染使用系统浏览器与简化布局；不使用 WebView2/当前浏览器内核 |
| 不支持 | 复杂本地模型推理；动态插件加载；高级可视化；实时在线调度；全量自动升级 |

## 4. 安全补偿

- 不降低密码要求：正式密码方案仍须获批产品 + 受保护密钥句柄；Win7 分支
  仅复用 `mvp-prototype` 演示能力。
- Win7 分支关闭自动执行（任务包内脚本/宏/可执行文件一律不自动运行），
  与主分支一致。
- 系统时间异常与离线可信时间策略：与主分支一致的 fail-closed 处理。
- 已知限制（Win7 无现代 TLS/系统组件时）：以文档记录并默认走离线任务包
  通道，不开启在线同步。

## 5. 测试计划

- 主分支质量门禁（`make quality`）持续绿。
- Win7 专项套件：`tests/win7/`（stdlib-only 导入检查、离线约束、允许/
  禁用组件清单），由 `scripts/win7-compat-check.ps1` 在 Win7 环境执行；
  未在 Win7 实机验证前，状态保持 `pending-win7-runtime`。
- 主分支与 Win7 分支分别记录验证结果（`loop/VERIFICATION.md`）。
